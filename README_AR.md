## 📱 عن المشروع

**حصن المسلم** هو تطبيق إسلامي حديث يجمع مجموعة من الأدوات والمحتوى الإسلامي اليومي في تجربة واحدة هادئة وسهلة الاستخدام.

يوفر التطبيق تجربة متكاملة تشمل قراءة القرآن والاستماع إليه، مواقيت الصلاة، الأذكار، الأحاديث، المحتوى التعليمي الإسلامي، اتجاه القبلة، التسبيح، التذكيرات، ومجموعة من الموارد الإسلامية الإضافية.

> **هذه المستودعة هي المستودعة العامة لعرض المشروع.**
>
> الكود المصدري الإنتاجي محفوظ في مستودعة خاصة منفصلة، ولذلك لا يتم تضمين Source Code أو ملفات التطوير الداخلية هنا.

- 🕌 مواقيت الصلاة ومعلومات الصلاة القادمة
- 📿 الأذكار وأذكار اليوم

- 📿 التسبيح الإلكتروني
- 🌙 التاريخ الهجري والمعلومات اليومية
- 🔔 التذكيرات اليومية القابلة للتخصيص

- 📚 قصص الأنبياء والمحتوى التعليمي
- ❓ الأسئلة والمحتوى الإسلامي التعليمي

# 📖 تجربة القرآن الكريم

تجمع تجربة القرآن بين القراءة والاستماع.

<p align="center">
  <img src="media/screenshots/04-quran-experience.png" width="100%" alt="تجربة القرآن">
</p>

### تصفح السور

يمكن للمستخدم تصفح السور والوصول إلى السورة المطلوبة من خلال قائمة منظمة.

### القراءة

واجهة مخصصة لقراءة النص القرآني مع التركيز على وضوح النص وسهولة التنقل.

### اختيار القارئ

يمكن اختيار القارئ قبل الانتقال إلى تجربة الاستماع.

# 🛠️ التقنيات

تم بناء التطبيق باستخدام:

| المجال | التقنية |
|---|---|
| إطار التطبيق | Flutter |
| اللغة | Dart |
| إدارة الحالة | BLoC / Cubit |
| الخدمات | Firebase + APIs |
| الصوتيات | Flutter Audio Ecosystem |
| الإشعارات | Local Notifications |
| الموقع | Geolocation |
| الفيديو | YouTube Integration |

> تفاصيل التنفيذ الداخلية والكود المصدري وملفات الإعدادات الخاصة غير موجودة في هذه المستودعة العامة.
