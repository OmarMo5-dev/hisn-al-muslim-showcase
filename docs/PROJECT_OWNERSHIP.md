## Purpose of this document

This document records the public attribution statement for the project showcase
repository. It is intended to make the repository's ownership and non-open-source
status clear to visitors.

The production application source code is maintained separately in a private
repository. This public repository is intentionally limited to documentation,
screenshots, branding, and other showcase material.

## What this document does not claim

A text file in a public repository is not, by itself, a legal determination of
copyright ownership. Ownership and rights can also depend on authorship records,
contracts, third-party licenses, content licenses, distribution records, and
app-store/developer-account records.

For that reason, when the application is distributed publicly, keep the same
developer identity and project name across the official GitHub profile,
distribution pages, and app-store listing where appropriate.
