# Security

This repository is a public showcase repository and does not contain the production
source code or private configuration of Hisn Al-Muslim.

## Reporting a security issue

Please do not publish security vulnerabilities, credentials, API keys, tokens, or
private configuration in public issues.

If you discover a security issue related to the publicly distributed application,
please contact the project owner privately through the official developer/project
contact channel.

## Important

Never commit:

- API keys
- Firebase service-account credentials
- OAuth secrets
- Signing keys / keystores
- `.env` files containing secrets
- Private backend credentials
